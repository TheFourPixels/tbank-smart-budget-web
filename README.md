# Умный бюджет

Веб-приложение для личного финансового планирования — ведите бюджет, контролируйте расходы по категориям и отслеживайте финансовые цели.

---

## Возможности

- **Бюджет** — создание бюджета на месяц с указанием дохода и лимитов по категориям
- **Категории** — управление категориями расходов: добавление в бюджет, изменение лимитов, удаление
- **Транзакции** — история операций с фильтрацией по месяцу и категории
- **Аналитика** — дашборд с графиками план/факт и расходами по категориям
- **Цели** — финансовые цели с прогресс-баром и рекомендуемой суммой пополнения

| | |
|---|---|
| UI | React 19, React Router 7 |
| Стили | CSS Modules + глобальный CSS |
| Иконки | react-icons |
| API | REST (fetch), JWT-авторизация |

---

## Запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm start
```

Приложение откроется на [http://localhost:3000](http://localhost:3000).  
Backend ожидается на `http://localhost:8080/api/v1`.

```bash
# Сборка для продакшена
npm run build
```

## Структура

```
src/
├── components/
│   ├── Auth/          # Формы входа и регистрации
│   ├── Budget/        # Главная страница бюджета, хедер
│   ├── Categories/    # Страницы категорий и статистики
│   ├── Transactions/  # Транзакции
│   ├── Goals/         # Финансовые цели
│   └── dashboard/     # Аналитика и графики
├── contexts/          # AuthContext (токен, пользователь)
├── services/          # API-клиенты
└── hooks/             # useBudget, useDashboard, useGoals
```

---

## Авторизация

Токен сохраняется в `localStorage` и автоматически восстанавливается при перезагрузке. Все защищённые маршруты требуют авторизации — неавторизованный пользователь перенаправляется на `/login`.
